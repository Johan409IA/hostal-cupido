# MEMORY.md — [Nombre del proyecto]

Memoria del proyecto entre sesiones de agente. Mantener en ~50 líneas: resumir o eliminar lo que ya no aporte en cada actualización, en vez de solo añadir al final.

```markdown
# MEMORY.md — [Nombre del proyecto]
Memoria del proyecto entre sesiones. Máximo ~50 líneas: resume o elimina lo que ya no aporte.

## Estado actual
- [Qué funciona hoy, en qué versión/fase está el proyecto.]

## Decisiones (y por qué)
- [Decisión] — [razón breve].

## Aprendizajes y errores a evitar
- [Algo que falló o sorprendió, y cómo evitarlo la próxima vez.]

## Próximos pasos
- [Lo siguiente que hay que hacer, si ya se sabe.]
```

## Reglas al actualizar

- Si una decisión deja de ser "de este momento" y se vuelve una regla permanente (p. ej. "decidimos no usar X" pasa a ser "nunca usar X"), muévela a `AGENTS.md` y bórrala de aquí.
- No dejes crecer indefinidamente las secciones: cuando algo ya no es relevante para entender el estado actual, elimínalo en vez de acumularlo.
- Nunca guardar claves, tokens, ni datos personales.
